# MASTER PROMPT — BUILD INTELLIROUTE FROM SCRATCH

You are a senior full-stack developer, Neo4j graph database engineer, UI/UX designer, and machine-learning engineer.

Build a complete, working academic DBMS case-study application called:

# IntelliRoute

### Intelligent Last-Mile Delivery Failure Prediction and Logistics Analytics System

The project must be implemented as a **real working web application**, not a static prototype.

The most important requirement is that **Neo4j must be the core database**, and all important application operations must actually interact with Neo4j.

The application must clearly demonstrate database concepts through the user interface while solving a realistic last-mile delivery problem.

---

# 1. PROBLEM STATEMENT

Last-mile delivery failures caused by incorrect addresses, customer unavailability, repeated delivery attempts, and logistical issues increase operational costs and customer dissatisfaction in e-commerce.

IntelliRoute is a graph-based logistics management and analytics system using Neo4j to model and analyze the relationships among customers, addresses, orders, shipments, delivery agents, hubs, delivery attempts, delivery zones, and failure reasons.

The system should allow logistics data to be created, updated, retrieved, searched, and analyzed through a web application.

Historical delivery data should be analyzed using machine learning to predict the probability of delivery failure for individual shipments.

The application should provide operational dashboards, graph-based relationship exploration, failure-pattern analysis, delivery performance metrics, and high-risk shipment identification to support proactive logistics decision-making and reduce failed deliveries and returns.
